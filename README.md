# 🏛️ Troia Equipamentos - Site Institucional

Site de consultoria em licitações públicas para a empresa Troia Equipamentos.

## 📋 Sobre o Projeto

Um site institucional profissional desenvolvido para divulgar os serviços de assessoria e consultoria em licitações públicas da Troia Equipamentos. O site é responsivo, moderno e otimizado para conversão de leads via WhatsApp.

### ✨ Características

- ✅ Design profissional e corporativo
- ✅ 100% responsivo (mobile, tablet, desktop)
- ✅ Integração com WhatsApp (wa.me)
- ✅ Menu mobile funcional
- ✅ Animações suaves
- ✅ Performance otimizada
- ✅ Fácil manutenção

## 📁 Estrutura do Projeto

```
TROIA/
```

## 🚀 Como Usar

### Abrir no Navegador

1. Abra o arquivo `index.html` diretamente no navegador, ou
2. Use um servidor local (Live Server)

### Editar Conteúdo

1. Abra `index.html` em um editor de código
2. Altere o texto dentro das tags HTML
3. Salve o arquivo
4. Atualize o navegador

### Personalizar Estilos

1. Abra `css/style.css`
2. Altere cores nas variáveis CSS (`:root`)
3. Salve e atualize o navegador

### Adicionar Interatividade

1. Abra `js/interatividade.js`
2. Adicione novas funcionalidades
3. Salve e atualize o navegador
